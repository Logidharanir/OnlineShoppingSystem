# Online Shopping System - MySQL Project

## 📌 Project Overview
This project is a basic e-commerce system using MySQL. It includes:
- Product, Customer, Orders, and OrderDetails tables
- Sample data insertion
- Stock update logic on orders

## 📂 Files
- `OnlineShoppingSystem.sql`: Full SQL script with schema and sample data
